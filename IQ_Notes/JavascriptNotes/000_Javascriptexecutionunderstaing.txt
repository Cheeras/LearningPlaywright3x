Execution Context is like big box and it has 2 components in it 

1. Memory component - This is the place where all the variable and functions are stored as key value pair
    There is also heavy word for this memory component is called Variabld environment

    Example:
    key : value

2. Code Component : This is place where code is execute one line at a time 
                    Just like Memory componet there is also heavy word for this code component is called Thread of Execution
